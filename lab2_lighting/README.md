# Лабораторная работа 2

**Вариант 7 — тор.** Выполнены базовое задание и все дополнительные задания 1–4.

## Условие

Реализовать камеру с возможностью её перемещения и освещение по модели
Блинн–Фонга с несколькими типами источников света. Vulkan, GLFW и ImGui;
программа работает в реальном времени, камера, источники света и материалы
моделей настраиваются из интерфейса.

| Задание | Где в интерфейсе | Где в коде |
|---|---|---|
| Камера: позиция, поворот, угол обзора | **Camera** | `computeViewProjection` |
| Направленный источник и рассеянный свет | **Directional light**, **Ambient light** | `shaders/model.frag` |
| Материал: альбедо, цвет блика, коэффициент блика | **Torus → Material**, **Floor** | `ModelUniforms` |
| Нормали вершин, сгенерированные процедурно | — | `torus::normal`, `plane::generate` |
| 1. Два набора дескрипторов: сцена (uniform + storage-буферы источников) и модель (матрица + материал) | — | `createDescriptors`, `shader_data.hpp` |
| 2. Массив точечных источников из storage-буфера, затухание 1/d², добавление и удаление | **Point lights** | `uploadLights`, `shaders/model.frag` |
| 3. Массив прожекторов из storage-буфера, затухание 1/d², мягкие края при внешнем угле больше внутреннего | **Spot lights** | `uploadLights`, `shaders/model.frag` |
| 4. Визуализация источников: куб цвета источника, белый конус прожектора, без освещения | **Light sources** | `gizmos.cpp`, `shaders/gizmo.*` |

Сцена — тор и пол, у каждой модели свой набор дескрипторов с матрицей и
материалом. Из лабораторной работы 1 сохранены трансформации и анимация тора,
переключение перспективной и ортографической проекции, процедурные цвета вершин
и параметры сетки тора (секция **Torus**).

## Сборка и запуск (macOS)

Нужны Xcode Command Line Tools, CMake, Ninja и Vulkan SDK (с `glslc`). При первой
настройке CMake скачивает GLFW, vk-bootstrap, VMA и ImGui, поэтому нужны интернет
и `git`.

Все команды выполняются **из папки лабы**: шейдеры загружаются по относительному
пути `shaders/*.spv`.

```bash
source ~/VulkanSDK/<версия>/setup-env.sh
cmake --preset debug
cmake --build build-debug --parallel
./build-debug/vulkan-starter-app
```

Шейдеры из папки `shaders` компилируются в SPIR-V автоматически при сборке.

## Система координат

- +X вправо, +Y вниз, +Z вглубь экрана; «вверх» — это −Y, нормаль пола (0, −1, 0);
- после проекции x, y ∈ [−1, 1], глубина ∈ [0, 1] (как в Vulkan);
- матрица камеры `T · Ry · Rx · Rz`, матрица вида — обратная к ней:
  `V = Rz(−z) · Rx(−x) · Ry(−y) · T(−позиция)`; отрицательный поворот по X наклоняет камеру вниз;
- модель: `M = T · Rz · Ry · Rx · S`, нормали преобразуются матрицей `Rz · Ry · Rx · S⁻¹`;
- векторы-столбцы: `p' = P · V · M · p`; матрицы хранятся по столбцам, как `mat4` в GLSL;
- лицевая грань — обход по часовой стрелке, задние грани отсекаются;
- направление источника света — куда он светит.
